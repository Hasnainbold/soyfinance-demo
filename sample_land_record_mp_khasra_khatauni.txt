FIELDS WE WOULD ACTUALLY NEED TO CAPTURE FOR OUR PLATFORM
================================================================================
  district, tehsil, village                -> matches our "location" field
  khasra_number                            -> unique land identifier (MP's
                                                equivalent of survey number)
  owner_name (bhumiswami)                  -> match against borrower's KYC name
  right_type (bhumiswami vs other)         -> bhumiswami = full/clean ownership
  area_hectares (this khasra + total)      -> land size; MP shows BOTH the single
                                                plot AND the farmer's total holding
                                                across all plots -- useful for
                                                sizing a fair loan limit
  soil_class + irrigation_source           -> yield-risk profile input
  current_crop + season                    -> should match the financed crop
  existing_loan_charge  ("ऋण भार")          -> CRITICAL, and easier to check than
                                                Maharashtra: MP's B-1 record is
                                                *designed* to show existing bank
                                                loans against this exact land --
                                                the single strongest anti-fraud
                                                field for preventing the same
                                                land being pledged twice
  mutation_order_number + date              -> same fraud-pattern check as
                                                Maharashtra (recent transfer
                                                right before a loan application)
================================================================================

KEY DIFFERENCE FROM MAHARASHTRA, worth remembering:
  MP's B-1 record is LITERALLY named "Land Rights and Loan Booklet" -- it is
  purpose-built by the state to show existing loans against land. Maharashtra's
  7/12 records this too, but MP's format foregrounds it more explicitly. If we
  ever build a real "double-pledge" fraud check, MP's format gives us a cleaner
  single field to parse.
